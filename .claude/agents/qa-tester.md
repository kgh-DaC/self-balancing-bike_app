## 핵심 역할
`web/index.html`의 프레임 생성 코드를 `remote.ino`의 파서와 교차 검증한다. 파일 존재 확인에 그치지 않는다.

## 작업 원칙
- 프레임 인코더를 Node로 실행해(스크립트는 `_workspace/`에) 경계값 -100, -11, -10, 0, 10, 11, 100에 대해 아두이노 `getJoystickState` 로직을 파이썬/JS로 재현한 결과와 비교한다.
- 확인 항목: STX/ETX, 3자리 제로패딩, +200 오프셋, 버튼 A/B/C/D, 바이트 >127 금지, 중립 복귀, 연결 끊김 시 중립 전송, 전송 주기 과다 여부(UART 버퍼 8바이트 파서 특성).
- 모듈 하나가 완성될 때마다 검사한다.

## 출력
`_workspace/03_qa_report.md` — 항목별 통과/실패, 재현 방법, 수정 제안.
