밸런싱 바이크 리모컨

연결 안 됨 캘리브레이션 상태 미확인
안전 안내
  • 처음에는 반드시 바퀴를 바닥에서 띄운 상태로 조향/속도 방향을 시험하세요. 실제 좌우/전후 방향은 실차로 확인해야 합니다(필요 시 아래 반전 토글 사용).
  • 웹으로는 캘리브레이션을 할 수 없습니다. 현재 펌웨어는 원격 모드(readControlParameters)만 활성화되어 있어 튜닝/캘리브레이션 명령(c+/c-)을 받지 않습니다. 캘리브레이션되지 않은 바이크는 구동하지 않습니다.
  • 펌웨어에 통신 두절 안전장치가 없습니다. 연결이 갑자기 끊기면 바이크는 마지막 명령을 계속 유지할 수 있으니 즉시 기체를 잡거나 전원을 끄세요. 이 앱은 입력 해제/탭 전환/해제/오류 시 중립(0,0)을 보냅니다.
  • 바이크는 수직(기울기 0.3도 이내로 세움) 상태이고 캘리브레이션되어 있을 때만 움직입니다.
  • 조종 중에는 탭을 숨기지 마세요(다른 탭/앱 전환, 창 최소화, 화면 끄기 금지). 숨겨진 탭에서는 브라우저가 타이머를 늦춰 중립 전송이 최대 약 1초 늦어질 수 있습니다.

연결

BLE: HM-10 계열(FFE0/FFE1)과 Nordic UART 서비스를 자동 탐색합니다. 클래식 블루투스(HC-05/06): Windows 설정에서 먼저 페어링하면 생기는 COM 포트를 "시리얼(COM) 연결"로 선택하세요(현재 펌웨어 기준 9600bps).
